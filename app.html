ℹ️ About FieldBook Pro

FieldBook Pro helps field researchers run pesticide trials offline: calculate accurate spray doses and record plot-by-plot observations in the field — no internet required.

Four tools in one: (1) convert g a.i./ha into product per hectare/acre and per plot, (2) mL per litre and per tank, (3) percentage solutions, and (4) ppm solutions. Pick a tab, type your numbers, tap Calculate — each result shows the answer, units, and the steps used. Area conversion uses 1 hectare = 2.5 acres.

Set up your trial (treatments, replications, observations), record subsample data and photos per plot, track progress, view treatment summaries, and export everything to CSV or Excel. Your data is saved on this device automatically.

  • Use the ☰ menu (top-left) to move between sections.
  • Tap the title bar to return Home anytime.
  • Switch between English and 中文 with the EN / 中 buttons.
  • Works fully offline. Weather and Excel export need internet on first use.
  • Offline-first: data entry & all dose calculations work with no internet.
  • Five dose tools: g a.i./ha→product & per-plot, mL/L & per-tank, % solution, ppm, and farmer-practice conversion.
  • Trial setup: treatments, replications, UTC, and multiple observations with assessment intervals.
  • Multi-column observations: each sub-column (e.g. Small / Large) is recorded per subsample.
  • RBD trial map: drag-to-reorder, randomize, serpentine walk, smooth horizontal scroll.
  • Plot numbering: ARM (Rep×100+Pos) and Treatment×Rep (T1R1…).
  • GPS capture (high-accuracy) for the field centre and four corners; open location in Maps.
  • Per-plot subsample data entry with photos — native camera, gallery pick, or file pick.
  • Full-resolution photos saved into a per-trial Photos subfolder on the device.
  • Voice dictation using the phone's system recognizer, in the active UI language.
  • Progress tracking and treatment summaries (means, efficacy, DSI, yield conversion).
  • Weather fetch (Open-Meteo) for the trial date range, cached offline, with retry on failure.
  • Export to CSV and ARM Excel — auto-fitted columns; each observation column gets its own sheet; weather on its own sheet.
  • PowerPoint (.pptx) summary export.
  • Backup & restore via the native file picker; recent-files list re-opens saved trials.
  • Storage folder (Android SAF): you pick it once; a FieldBook Pro folder with Raw Data and Photos subfolders is created automatically.
  • Languages: Auto / English / 中文 / Español (LatAm) / Español (España) / Bahasa Indonesia / Tiếng Việt.
  • App Lock: fingerprint / face / PIN or password on open (optional).
  • First-launch setup: profile, security, and storage-folder selection.
  • Share files to any app (WhatsApp, Gmail, Bluetooth…): pick CSV / Excel / PowerPoint with checkboxes and send in one tap.
  • Live export progress bar above the tab bar — a blue bar that climbs smoothly per slide during PowerPoint / Excel / CSV export.
  • “Downloaded to…” confirmation showing the exact folder each file was written to.
  • Crash-safe autosave: your work is written to disk on every change and automatically recovered after an unexpected close.
  • Location-off prompt: if GPS is disabled, one tap opens the device location settings.
  • Frozen Plot & Subsample columns in data entry — they stay pinned while data columns scroll sideways.
  • Mode-aware file/folder naming: photo and raw-data folders follow the chosen plot numbering (ARM → 101, 102… or T-R → T1R1…).
  • Data columns defined in Setup stay in sync with the Entry grid automatically.
  • Dates shown as DD-Mon-YYYY throughout the app and exports.

Your backups, CSV / Excel files and full-resolution photos are written into the FieldBook Pro folder on your device, organised per trial with Raw Data and Photos subfolders.
